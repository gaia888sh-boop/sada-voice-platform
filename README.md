# منصة صدى (Sada Voice Platform)

منصة متقدمة لتسجيل وتفريغ الصوت العربي بالذكاء الاصطناعي، وفصل المتحدثين، واستخراج الملخصات التلقائية، وبطاقات المراجعة، والخرائط الذهنية.

---

## 🚀 طريقة التشغيل محلياً (Quick Start)

### المتطلبات الأساسية:
- **Node.js** (الإصدار 18 أو أحدث)
- **npm** أو **pnpm** أو **yarn**

### خطوات التثبيت والتشغيل:

1. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

2. **إعداد المتغيرات البيئية:**
   قم بنسخ ملف الإعداد النموذجي:
   ```bash
   cp .env.example .env
   ```
   ثم افتح ملف `.env` وضع مفتاح Google Gemini API الخاص بك:
   ```env
   GEMINI_API_KEY="YOUR_GEMINI_API_KEY_HERE"
   ```

3. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```

4. **فتح التطبيق في المتصفح:**
   افتح الرابط: [http://localhost:3000](http://localhost:3000)

---

## 🛠️ بناء النسخة الإنتاجية (Production Build)

```bash
# بناء ملفات الواجهة
npm run build

# تشغيل الخادم
npm start
```

---

## ✨ المميزات الرئيسية
- 🎙️ **تسجيل صوتي حي وتفريغ فوري** متوافق مع مختلف اللهجات العربية.
- 📁 **استيراد ملفات الصوت (MP3, WAV, M4A, WebM)** مع ضغط فوري لتسريع الرفع.
- 👥 **فصل المتحدثين (Speaker Diarization)** وتمييز كل شخص بلون واسم مستقل.
- 📝 **محرر نصي متزامن** مع مشغل الصوت وعلامات الوقت الزمنية.
- 🧠 **أدوات ذكية متقدمة**: خرائط ذهنية، بطاقات استذكار واختبارات، تلخيص تنفيذي، محادثة صوتية مع التسجيل (RAG)، وإعادة صياغة وترجمة فورية.
